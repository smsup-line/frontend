# IP 205.185.127.97 - ข้อมูลและวิธีแก้ไข

## IP นี้คืออะไร?

**IP `205.185.127.97`** เป็น:
- **Crypto Mining Pool Server** - Server ที่ใช้สำหรับ crypto mining (เช่น Monero/XMR mining)
- **Malicious Server** - Server ที่ถูกใช้โดย attackers เพื่อ:
  - รับ mining connections
  - Download malicious scripts
  - Exfiltrate data
  - Control compromised systems

## ทำไมแจ้งเตือนตลอด?

### สาเหตุที่เป็นไปได้:

1. **Dependencies ที่ถูก Compromised**
   - Package ใน `node_modules` ที่ถูก inject malicious code
   - Package ที่พยายาม connect ไปที่ mining pool server
   - Postinstall scripts ที่ download และ execute malicious code

2. **Container ที่ถูก Compromise**
   - Malicious process ที่รันอยู่แล้วใน container
   - Process ที่ถูก inject โดย attackers
   - Cron jobs ที่ถูก setup โดย malicious code

3. **DNS Resolution**
   - Domain name ที่ resolve ไปที่ IP นี้
   - Malicious domain ที่ถูก inject ใน dependencies
   - Telemetry/analytics services ที่ถูก redirect

4. **Build Process**
   - Environment variables ที่ถูก inject
   - Build scripts ที่ถูก modify
   - Docker image base ที่ถูก compromise

## วิธีแก้ไข

### 1. Kill Malicious Processes
```bash
# ตรวจสอบ processes
docker exec sfadmin-nextjs ps aux | grep -E 'sh|mining|monero|xmr|205.185.127.97'

# Kill processes ที่น่าสงสัย
docker exec sfadmin-nextjs pkill -f mining
docker exec sfadmin-nextjs pkill -f monero
docker exec sfadmin-nextjs pkill -f xmr
```

### 2. Block IP ที่ DNS Level
Error handler จะ block IP นี้แล้ว แต่ถ้ายังมีปัญหา:
- Block ที่ firewall level
- Block ที่ Docker network level
- Block ที่ DNS level

### 3. Rebuild Container
```bash
docker-compose -f docker-compose.prod.yaml down
docker-compose -f docker-compose.prod.yaml build --no-cache
docker-compose -f docker-compose.prod.yaml up -d
```

### 4. ตรวจสอบ Dependencies
```bash
npm audit
npm audit fix
npm list | grep -E 'mining|monero|xmr|pool'
```

## สรุป

- **IP `205.185.127.97`** = Crypto mining pool server / Malicious server
- **แจ้งเตือนตลอด** = มี process หรือ dependency ที่พยายาม connect ไปที่ IP นี้ตลอดเวลา
- **วิธีแก้** = Kill malicious processes + Rebuild container + Block IP
